NEBULA PARALLAX PACK
====================
Game-ready, seamless space backgrounds with separated parallax layers.

WHAT'S INSIDE
  Each background lives in backgrounds/<NN_theme>/ and contains:
    layer1_far.png    - opaque deep-space base + distant starfield (slowest layer)
    layer2_nebula.png - transparent nebula clouds (mid layer)
    layer3_stars.png  - transparent bright foreground stars (fastest layer)
    preview.png       - all layers flattened (drop-in single-image background)
  contact_sheet.png   - grid preview of every background
  manifest.json       - machine-readable index

RESOLUTION
  1920 x 1080 (16:9). Scale down freely; scale up sparingly.

SEAMLESS TILING
  Every layer tiles HORIZONTALLY. Place two copies side by side and scroll for
  an infinite side-scrolling starfield with no visible seam.

PARALLAX SETUP (any engine)
  Stack the three layers and scroll them at different speeds, slowest at the back:
    layer1_far   x0.2
    layer2_nebula x0.5
    layer3_stars  x1.0
  Loop each layer's X by its width for endless scroll.
